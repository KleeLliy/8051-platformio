# 项目名称：8051 单片机工程项目模板

## 一、环境要求
- **VSCode**
- **uv** —— Python 包管理器
- **PlatformIO IDE** —— 跨平台嵌入式开发平台
- **操作系统：** Linux / Windows

## 二、使用步骤

### 1. 构建 Python 虚拟环境
&emsp;&emsp;安装 `uv` 后，在项目根目录执行：`uv sync`，该命令会依据 `pyproject.toml` 与 `uv.lock` 创建 `.venv/` 虚拟环境并安装所有依赖。

### 2. 编写源代码
源文件放进 `src/` 文件夹中

### 3. 构建项目
（1）编译快捷键：`Build`  
（2）烧录快捷键：`Upload`  
（3）清理快捷键：`Clean`
